## Troubleshooting Common Issues

Install issues? Confirm the capture hook works before a long run, since some games block overlay tools.  
Performance problems? Repeat the same route for every comparison to reduce noise.  
License/activation? Discard the first capture after a driver install, as shader compilation distorts results.  
Compatibility? Check that the game is not frame-limited differently between runs.  
Update failures? Export data before reinstalling to keep comparisons.
